# 클라우드플레어, AI ���이전트 토큰 사용량 99.9% 줄이는 코드 모드 MCP 서버 출시

**TECH & AI** | 2026.04.18 | SO,NOW

클라우드플레어가 2026년 4월 16일 코드 모드 기반 MCP 서버를 출시했다. AI 에이전트가 대규모 API와 상호작용할 때 토큰 사용량을 99.9% 절감하는 기술로, 2500개 이상 엔드포인트에서 컨텍스트 공간을 최적화하고 다중 API 조정을 개선하며 안전한 코드 중심 실행 환경을 제공한다.
