# 더네오, 사람과 AI 에이전트 모두를 위한 API 관리 플랫폼 공개

**AI** | 2026.05.16 | SO,NOW

API 문서화 도구 스타트업 더네오가 2026년 3월 넷째 주, 사람 개발자�� AI 에이전트를 모두 지원하는 올인원 API 관리 플랫폼 '엘바'를 출시했다. 이 플랫폼은 API 설계, 문서화, 관리, 관찰 기능을 통합 제공하며, 에이전트가 대규모로 API를 호출하는 환경에 최적화됐다. 더네오는 Y콤비네이터 출신으로 2022년 창업했다.
