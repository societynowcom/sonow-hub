# 브라우저 확장 프로그램 아키파이, 웹 앱 구조를 실시간으로 분석한다

**AI** | 2026.07.05 | SO,NOW

모드 살라후딘이 개발한 브라우저 확장 프로그램 아키파이가 2026년 제품헌트에 출시됐다. 이 도구는 웹 애플리케이션의 컴포넌트, API 호출, 라이브러리, 전체 아키텍처를 브라우저 내에서 실시간으로 분석해 보여준다. 모든 데이터는 로컬에서 처리되며 외부 서버로 전송되지 않는다.
