# Claude Code costs up to $200 a month. Goose does the same thing for free.

> 무료로 코드를 쓰는 AI, Goose가 등장한다. ## 저렴하지만 강력한 오픈소스 AI 개발 도구  Goose 는 사용자의 로컬 머신에서 작동하는 오픈소스 AI 코딩 에이전트

**AI** | 2026.02.10 | SO,NOW

Goose 는 사용자의 로컬 머신에서 작동하는 오픈소스 AI 코딩 에이전트로,  강력한 기능을 제공하며 무료로 이용 가능하다.

Goose는 Block(원래 Square)에서 개발되었으며, Anthropic's Claude Code와 같은 유사한 기능을 제공하지만 구독 비용 없이 사용자가 자신의 기기에서 실행할 수 있다. Goose는 사용자의 데이터를 안전하게 보호하며 인터넷 연결 여부와 상관없이 작동하여 개발자에게 큰 자유도를 제공한다.

최근 인공지능 코딩 기술은 소프트웨어 개발에 새로운 가능성을 열고 있다.  하지만, 강력한 AI 코딩 도구들은 높은 구독 비용 때문에 많은 개발자들에게 부담스러운 요소였다. 예를 들어 Anthropic의 Claude Code는 사용량 제한 및 월별 구독료 등으로 인해 개발자들의 불만을 받고 있다. 

Goose 는 이러한 문제점을 해결하기 위해 무료로 제공되는 오픈소스 AI 코딩 에이전트로서 주목받고 있다. Goose는  개발자가 로컬 머신에서 실행할 수 있도록 설계되어  인터넷 연결 없이도 사용 가능하며 데이터 보안 측면에서도 유리한 점을 가지고 있다.

Goose의 가장 큰 강점은 사용자에게 완벽한 통제권을 제공하는 것이다. 개발자는 자신의 기기에서 직접 AI 모델을 다
