Code Metal, AI로 코드 번역하는 스타트업 1250억 유치

군 산업부터 반도체까지, AI 코드 기술 경쟁 치열

AI | 2026.02.23 | SO,NOW

Code Metal은 2023년 설립된 스타트업으로 AI를 활용해 코드 번역 및 확인에 중점을 두고 있다. 회사는 최근 1250억 원의 B 라운드 자금을 Salesforce Ventures, Accel 등의 투자자로부터 확보했다. 이번 유치는 Code Metal이 36억 원의 A 라운드 자금 조달 직후, 약 9개월 만에 거래된 것이다. Code Metal은 AI 기술을 활용해 코드를 Python과 같은 고수준 언어에서 Rust와 같은 저수준 언어로 번역한다.

Code Metal의 주력 시장은 군 산업 및 반도체 분야이다. 회사는 L3Harris, RTX 등 기존 고객을 확보하고 있으며 Toshiba와의 파트너십을 통해 코드 포터빌리티 문제 해결에 나서는 중이다. Code Metal CEO Peter Morales는 AI가 코드 작성에 큰 영향을 미칠 것이라고 예상하며, 특히 군 산업과 같은 고성능 및 안전성이 요구되는 분야에서 AI 코드 기술의 필요성이 높아진다고 강조한다.
