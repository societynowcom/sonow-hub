# 지미 앱, 음악 생성 모델 업그레이드

**AI** | 2026.03.08 | SO,NOW

Google DeepMind가 개발한 새로운 음악 생성 모델 'Lyria 3'이 지미 앱에 적용되었습니다. 이를 통해 사용자는 텍스트 또는 이미지를 입력하여 30초 길이의 음악을 만들 수 있습니다. Lyria 3은 지미 앱의 음악 생성 기능을 더욱 강력하고 사용자 친화적으로 만듭니다.
