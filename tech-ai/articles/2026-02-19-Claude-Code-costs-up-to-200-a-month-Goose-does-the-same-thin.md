# Claude Code costs up to $200 a month. Goose does the same thing for free.

> 무료 오픈소스 AI 코딩 에이전트 'Goose' 출시   ## 무료로 프로그래밍: Goose가 새로운 가능성 열어  최신 기술 기반의 AI 코딩 도구들은 개발자들의 생산성을

**AI** | 2026.02.19 | SO,NOW

최신 기술 기반의 AI 코딩 도구들은 개발자들의 생산성을 높이는 데 도움이 된다. 하지만, 대부분은 사용권 구독 등 비용 부담과 제한적인 기능으로 인해 사용자가 불편하다. 이러한 문제점을 해결하기 위해 Block (Square의 전신)에서 무료 오픈소스 AI 코딩 에이전트 'Goose'를 출시했다. Goose는 기존 상용 상품인 Claude Code와 유사한 기능을 제공하지만, 사용자의 로컬 머신에서 작동하여 구독 비용이나 제한적인 사용 시간 없이 개발 작업을 지원한다.

Goose는  개발자가 직접 관리하고 다운로드할 수 있는 오픈소스 모델을 사용하는 방식으로, 데이터 보안과 프라이버시를 강조한다. 반면 Anthropic의 Claude Code는 클라우드 기반 서비스로 고가의 구독 비용이 부담이며, 사용 시간 제한 등 제약적인 요건을 가진다. Goose의 출시는 AI 코딩 도구 시장에서 무료 및 오픈소스 모델이 주목받고 있다는 것을 보여준다.
