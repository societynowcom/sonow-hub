# 24시간으로 이미지 생성 모델을 훈련하는 기술: Hugging Face의 PRX Part 3

> 혁신적인 프레임워크가 이미지 생성 분야에 변화를 가져올 수 있음

**AI NOW** | 2026.03.07 | SO,NOW

Hugging Face가 새롭게 개발한 PRX Part 3 프레임워크는 기존보다 훨씬 빠르고 효율적인 이미지 생성 모델 훈련을 가능하게 합니다. 이 기술은 단 24시간 만에 이미지 생성 모델을 훈련할 수 있도록 하여 이미지 생성 분야의 연구와 개발 속도를 크게 높일 수 있습니다.

PRX Part 3는 데이터 처리 및 모델 학습 과정을 최적화하여 훈련 시간을 단축합니다.
