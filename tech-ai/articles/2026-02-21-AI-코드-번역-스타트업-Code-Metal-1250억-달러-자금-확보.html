AI 코드 번역 스타트업 Code Metal, 1250억 달러 자금 확보

국방 산업부터 시작하여 모든 코딩 문제 해결하는 비전

AI | 2026.02.21 | SO,NOW

본토스톤 기반 스타트업 Code Metal은 인공지능(AI) 기술을 활용하여 코드를 작성하고 다른 프로그래밍 언어로 번역하는 서비스를 제공한다. 최근 Code Metal은 새로운 투자자들과 기존 투자자들의 참여로 1250억 달러의 시리즈 B 라운드 자금을 확보했다. 이는 지난 해 시리즈 A 라운드에서 Accel 주도로 확보한 360억 달러에 추가된 것이다. Code Metal은 AI를 활용하여 코드를 자동화하고 검증, 테스트, 보안하는 데 도움이 되는 기술을 개발하는 새로운 스타트업 파이프라인의 일부이다.

Code Metal은 설립된 지 불과 2년 만에 고객으로 L3Harris, RTX(전 Raytheon), 미국 공군 등 국방 산업 기업들을 확보했다. 또한 일본 전자 회사 Toshiba와도 파트너십을 맺고 있으며, 대규모 반도체 제조업체와도 협력 논의 중이라고 한다. Code Metal은 Python, Julia, Matlab, C++ 와 같은 고수준 프로그래밍 언어에서 Rust, VHDL 및 Nvidia CUDA와 같은 저수준 언어 또는 특정 하드웨어를 실행하는 코드로 번역하는 플랫폼을 제공한다. CEO Peter Morales는 기업들이 AI 생성 코드에 대한 솔루션을 찾기 시작하고 있다고 말하며, Code Metal이 이러한 문제 해결에 중점을 두고 있다고 설명했다.
