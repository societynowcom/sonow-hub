# 앤트로픽, 클로드 데스크톱 버디로 AI와 물리적 세계 연결하는 BLE API 공개

**AI** | 2026.04.22 | SO,NOW

앤트로픽이 2026년 4월 클로드 데스크톱 버디를 출시했다. 이 도구는 클로드 데스크톱 앱의 경량 BLE API를 노출하여 메이커들이 ESP32 같은 물리적 마이크로컨트롤러와 클로드 코워크, 클로드 코드를 연결할 수 있게 한다. 상태 표시, 권한 프롬프트 처리 등 다양한 상호작용을 구현 가능하다.
