# Claude Code costs up to $200 a month. Goose does the same thing for free.

> 무료 AI 코딩 에이전트, Goose가 등장했다. ## 클라우드 의존 없이 완전히 자유로운 개발 환경 제공 Goose는 블록(Square)에서 개발된 오픈소스 AI 에이전트로

**AI** | 2026.02.09 | SO,NOW

Goose는 블록(Square)에서 개발된 오픈소스 AI 에이전트로, Claude Code와 같은 기능을 제공하지만 무료이며 클라우드 의존도가 없다. 


오픈-소스 언어 모델을 사용하여 기본적인 작업부터 복잡한 프로젝트까지 수행하며, 지역에서 실행되므로 구독 비용이나 사용 제한이 없다.  

데이터는 사용자의 기기 내에만 저장되어 개인정보 보호에도 강점이 있다. 또한, 온라인 연결이 없는 환경에서도 작동 가능하다는 장점이 있다.

Goose는 다양한 오픈소스 모델을 지원하는 "모델-무관" 방식을 채택하며, 사용자는 
Claude 4 모델까지 활용할 수 있다. 하지만, 현재 최고급 AI를 제공하는 Claude Code와 비교하면  문맥 창 크기 및 처리 속도에서 약간 뒤처진다.
