AI 에이전트가 소셜미디어에 직접 글을 올린다, 퍼블로라 MCP API 출시

AI | 2026.06.12 | SO,NOW

퍼블로라가 2026년 6월 10일 AI 에이전트 전용 소셜미디어 API를 출시했다. REST API 호출 한 번으로 링크드인, X, 인스타그램, 스레즈, 틱톡, 유튜브, 페이스북, 블루스카이, 마스토돈, 텔레그램 등 10개 플랫폼에 동시 게시할 수 있다. MCP 네이티브 서버와 18개 도구를 통해 클로드, 커서 등 AI 에이전트가 게시, 댓글, 리액션, 분석 조회까지 전체 참여 루프를 수행한다. 무료 티어와 계정당 월 2.99달러 유료 요금제를 제공한다.
