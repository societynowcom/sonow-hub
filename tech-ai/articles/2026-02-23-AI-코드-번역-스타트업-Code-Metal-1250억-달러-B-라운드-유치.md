# AI 코드 번역 스타트업 Code Metal, 1250억 달러 B 라운드 유치

> AI 기반 코드 생성 기술, 국방 산업부터 반도체까지 적용

**AI** | 2026.02.23 | SO,NOW

Code Metal은 2023년 설립된 미국 보스턴 기반 스타트업으로, AI를 활용하여 코드 생성과 번역 서비스를 제공합니다. 최근 A 라운드 이후로 새롭게 투자를 확보하며 전 세계적으로 주목받고 있습니다.  특히 국방 산업 분야에 중점을 두고 있으며 L3Harris, RTX(Raytheon) 등의 기업들과 파트너십을 구축했습니다. 또한 일본 전자 제품 회사 Toshiba와도 협력하고 반도체 플랫폼 간 코드 포터빌리티 기술 개발에도 박차를 가하고 있습니다.

Code Metal은 고수준 프로그래밍 언어(Python, Julia, Matlab, C++)에서 저수준 언어 또는 특정 하드웨어에 실행되는 코드로 변환하는 기술을 보유하고 있습니다.  특히 AI 기반으로 코드 검증 기능을 제공하여 부가적인 가치를 창출합니다. CEO Peter Morales는 과거 Microsoft와 MIT Lincoln Laboratory에서 근무하며 경험을 쌓았고, 현재 Code Metal의 시장 진출 및 성장에 큰 영향력을 행사하고 있습니다.
