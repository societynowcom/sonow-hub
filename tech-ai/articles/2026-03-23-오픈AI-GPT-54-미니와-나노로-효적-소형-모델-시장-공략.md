# 오픈AI, GPT-5.4 미니와 나노로 효��적 소형 모델 시장 공략

**AI** | 2026.03.23 | SO,NOW

오픈AI가 2025년 7월 17일 GPT-5.4의 소형 버전인 '미니'와 '나노'를 발표했다. 코딩, 도구 사용, 멀티모달 추론에 특화된 이 모델들은 기존 대비 더 빠른 속도와 낮은 비용으로 고용량 API 및 서브에이전트 작업을 처리할 수 있다. 한국 개발자 커뮤니티의 접근성 향상과 엣지 컴퓨팅 적용 가능성을 열었다.
