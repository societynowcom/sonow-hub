인공지능 코드 번역 스타트업 Code Metal, 1250억 달러 자금 확보

AI 기반 코드 생성으로 새로운 가치 창출

AI | 2026.02.21 | SO,NOW

Code Metal은 2023년 설립된 스타트업으로, 최근 A 라운드 자금 조달 이후 B 라운드에서 새로운 투자를 받았습니다. 이번 1억 2,500만 달러의 B 라운드 자금을 Salesforce Ventures와 Accel 등이 주도했습니다. Code Metal은 AI 기술을 활용하여 코드 생성 및 번역하는 플랫폼을 제공하며, 국방 산업 분야에서 L3Harris, RTX, US Air Force와 같은 기업과 협력하고 있습니다.

Code Metal의 주요 목표는 고수준 프로그래밍 언어 (Python, Julia, Matlab, C++)를 저수준 언어 또는 특정 하드웨어에 실행 가능한 코드로 번역하는 것입니다. AI 기반 기술을 통해 코드 수정 및 포트링 문제를 해결하며, 회사는 이러한 솔루션이 오래된 코드 베이스의 현대화에 도움을 줄 것이라고 주장합니다.
