# 무료 AI 코드 생성 도구 Goose, 개발자들의 주목받아

> 클라우드 의존 없이 자유로운 코딩 경험 제공

**AI** | 2026.02.26 | SO,NOW

최근 AI 기반 코드 생성 도구가 급속히 발전하면서  개발자들의 생산성 향상에 큰 영향을 미치고 있습니다. 하지만 상용 서비스는 높은 구독비와 사용 제한으로 인해 개발자들에게 부담이 되기도 합니다. 이러한 문제점을 해결하기 위해 블록에서 무료 오픈 소스 AI 코드 도구 Goose를 개발했습니다.

Goose는 사용자의 로컬 머신에 설치하여 작동하는 "온-머신 AI 에이전트"입니다. 클라우드 서비스와 달리 구독 비용이나 사용 제한 없이도 이용할 수 있습니다. 또한, 다양한 오픈 소스 언어 모델을 지원하며, 사용자가 원하는 모델을 선택하여 활용할 수 있습니다.

Goose는 단순히 코드 생성 기능뿐만 아니라, 새로운 파일 작성, 테스트 실행, GitHub 리퀘스트 상태 확인 등 복잡한 개발 작업까지 자동화합니다.  "툴콜링" 기술을 통해 외부 시스템과 상호 작용하며, 사용자의 명령을 실제로 실행하여 더욱 효율적인 코딩 환경을 제공합니다. Goose는 Ollama와 같은 도구를 통해 오픈 소스 모델을 사용할 수 있으며, 이는 클라우드 기반 서비스보다 낮은 비용으로 강력한 AI 기능을 활용할 수 있게 합니다.
