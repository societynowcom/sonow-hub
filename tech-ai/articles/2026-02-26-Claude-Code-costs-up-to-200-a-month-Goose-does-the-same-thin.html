실질적인 개발자의 자율성을 강조합니다.

최근 AI 코딩 도구 시장에서 Anthropic의 클라우드 기반 AI 에이전트 Claude Code가 주목받고 있습니다. 하지만, $20~ $200/월 가격과 사용 제한으로 인해 개발자들의 반발이 일고 있습니다. 이에 Block(구 Square)에서 오픈소스 AI 코딩 도구 Goose를 출시하여 이러한 문제점을 해결하고자 합니다. Goose는 사용자가 로컬 머신에 설치하여 운영할 수 있는 오픈소스 AI 에이전트로, 사용료 없고, 데이터 프라이버시 보장으로 인해 많은 개발자들의 관심을 받고 있습니다.

Goose의 주요 특징은 사용자가 자유롭게 선택할 수 있는 다양한 언어 모델 지원과 로컬 운영 환경입니다. 개발자는 Ollama와 같은 도구를 사용하여 Goose에 원하는 언어 모델을 연결하고 로컬 머신에서 실행할 수 있습니다. 이는 클라우드 의존성 없이 오프라인에서 작업 가능하게 하며, 데이터 프라이버시 문제에도 적극적으로 대처합니다.

Goose는 단순한 코드 제안 기능을 넘어 실제로 개발 프로세스를 자동화할 수 있는 "툴콜링" 기능을 제공합니다. 사용자가 직접적인 명령 없이도 AI가 파일 생성, 테스트 실행, API 호출 등 다양한 작업을 처리하여 개발 효율성을 높입니다.
