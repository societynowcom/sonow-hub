# Gradio로 웹 어플 하나로 만들기

> 간편한 UI 구축으로 AI 모델 활용 용이

**AI** | 2026.02.26 | SO,NOW

Gradio는 Hugging Face가 개발한 오픈소스 라이브러리입니다. 쉽고 빠르게 머신러닝 모델을 웹 애플리케이션에 통합할 수 있도록 지원합니다. 특히 gr.HTML 기능은 HTML 코드를 사용하여 UI를 디자인할 수 있어 사용자 인터페이스 구축이 더욱 간편해졌습니다. 이는 코딩 경험이 부족한 사람들도 AI 모델을 활용하여 웹 애플리케이션을 개발할 수 있도록 돕습니다.

gr.HTML 기능은 Gradio의 강력한 장점 중 하나입니다.  기존에 Python 코드만으로 UI를 구축해야 하는 어려움을 해결하고, HTML과 CSS를 활용하여 직관적인 인터페이스를 만들 수 있도록 합니다. 또한,  Gradio는 다양한 머신러닝 모델(예: 이미지 분류, 텍스트 생성)을 지원하며, 이러한 모델들을 웹 애플리케이션에 통합하고 사용자에게 결과를 표시하는 데 유용합니다.
