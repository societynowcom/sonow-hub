구글, LLM 후훈련 파인튜닝 전용 오픈소스 API '오픈알엘' 공개

TECH & AI | 2026.06.25 | SO,NOW

구글 지케이이랩스가 LLM 후훈련 파인튜닝을 위한 자체 호스팅 API '오픈알엘'을 오픈소스로 공개했다. 표준 쿠버네티스 클러스터에서 강화학습 인프라를 AI 연구로부터 분리해 GPU 유휴 시간을 줄이고 연구자와 엔지니어 역할을 명확히 구분한다. 기존 순차적 알엘 루프의 비효율을 개선, 여러 작업을 동시에 실행해 GPU 활용도를 높일 수 있다.
