유럽발 AI 게이트웨이 오퍼, API 하나로 300개 모델 통합

AI | 2026.07.11 | SO,NOW

스웨덴 스타트업 오퍼 AI가 2026년 300개 이상 AI 모델을 하나의 API 키로 연결하는 게이트웨이를 출시했다. EU 내 인퍼런스 호스팅, 기본 프롬프트 미저장, 개인식별정보 마스킹 등 데이터 주권을 핵심으로 내세웠다. 오픈AI·앤트로픽·구글 SDK와 드롭인 호환되며 클로드 코드나 커서에 한 줄만 붙여넣으면 바로 작동한다. 5만 명 이상 개발자가 사용 중이며 10만 명 이상 최종 사용자에게 서비스를 제공한다.
