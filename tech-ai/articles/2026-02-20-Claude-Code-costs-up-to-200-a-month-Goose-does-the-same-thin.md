# Claude Code costs up to $200 a month. Goose does the same thing for free.

> Goose : 무료 오픈소스 AI 코딩 도구, 개발자들의 주목받아  ## 로컬 실행 AI 에이전트 강력한 기능 제공 Goose는 블록에서 개발된 무료 오픈소스 오픈-소스 AI

**AI** | 2026.02.20 | SO,NOW

Goose는 블록에서 개발된 무료 오픈소스 오픈-소스 AI 에이전트로  클라우드 기반 서비스와 달리 사용자의 로컬 머신에서 작동합니다.

최근 인공지능 코딩 도구 시장에서 클라우드 기반 서비스가 주를 이루지만, 높은 구독 비용과 사용 제한 등의 문제로 개발자들의 불만이 커지고 있습니다. 그에 반해 Goose는 20GB RAM 이상을 가진 PC 환경에서 무료로 운영되는 오픈소스 AI 코딩 도구로 주목받고 있습니다.  Goose는 다양한 LLM(Large Language Model)과 연동 가능하며, OpenAI의 GPT-5나 Google의 Gemini 등을 이용하여 사용자가 원하는 모델을 선택할 수 있습니다.

Goose는 개발자가 자신의 하드웨어에 AI 모델을 직접 설치하고 운영할 수 있다는 점에서 큰 차별성을 가지고 있습니다.  이는 데이터 보안과 개인 정보 보호라는 관점에서 유리하며, 인터넷 연결이 불안정한 환경에서도 작동할 수 있는 장점이 있습니다. 또한, Goose는 Ollama와 같은 도구를 사용하여  원하는 모델을 선택하고 설정할 수 있어 다양성이 뛰어나다는 평가를 받고 있습니다.
