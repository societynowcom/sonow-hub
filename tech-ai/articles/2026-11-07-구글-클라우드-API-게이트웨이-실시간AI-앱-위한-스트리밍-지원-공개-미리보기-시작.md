# 구글 클라우드 API 게이트웨이, 실시간·AI 앱 위한 스트리밍 지원 공개 미리보기 시작

**TECH & AI** | 2026.11.07 | SO,NOW

구글이 2026년 11월 5일 클라우드 API 게이트웨이의 스트리밍 지원 공개 미리보기를 발표했다. 기존 요청-응답 모델을 확장해 실시간 통신이 필요한 AI 애플리케이션과 다단계 에이전트 워크플로를 지원하며, 서버 전송 이벤트와 웹소켓, gRPC 등이 포함된다.
