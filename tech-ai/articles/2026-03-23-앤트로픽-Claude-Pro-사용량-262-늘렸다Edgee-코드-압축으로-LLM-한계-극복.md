# 앤트로픽 Claude Pro 사용량 26.2% 늘렸다…Edgee, 코드 압축으로 LLM 한계 극복

**AI** | 2026.03.23 | SO,NOW

AI 스타트업 Edgee가 앤트로픽의 Claude Code 사용자들이 겪는 플랜 한도 문제를 해결하는 'Claude Code Compressor'를 출시했습니다. 이 솔루션은 프롬프트에서 불필요한 정보를 제거하여 토큰 사용량을 최대 50%까지 줄이고, Claude Pro의 작업 한도를 26.2% 연장합니다.
