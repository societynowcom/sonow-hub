# Lyria 3, 지메니 앱으로 출시! 텍스트와 이미지로 음악 제작 가능

> 사용자 정의형 고품질 짧은 음악 생성 기술

**AI** | 2026.02.23 | SO,NOW

Google AI는 최신 자연어 처리 기술을 기반으로 Lyria 3를 개발했습니다.  이는 사용자가 텍스트와 이미지 정보를 입력하면 음악적 요소들을 자동으로 생성하여 고품질 음악 파일을 만들 수 있도록 지원합니다. 이전 버전과 비교했을 때, Lyria 3는 더욱 정교하고 다양한 음악 스타일을 제작할 수 있는 기능을 제공합니다.

Lyria 3의 주요 특징은 사용자 친화적인 인터페이스와 광범위한 음악 구성 가능성입니다.  사용자들은 간단하게 원하는 음악 장르, 분위기, 악기 등을 입력하여 Lyria 3가 자동으로 맞춤형 음악을 생성합니다. 또한, 사용자가 직접 특정 음계나 리듬을 제시할 수도 있어 더욱 정밀하고 독창적인 음악 제작이 가능해졌습니다.
