# 프루 AI, 맥 앱 자동화 비용 0원으로 낮추는 AOT 컴파일 기술 공개

**AI** | 2026.05.26 | SO,NOW

프루 AI가 맥용 AI 에이전트를 출시했다. 사용자가 자연어로 데스크탑 앱 간 워크플로를 한 번 컴파일하면, 이후 반복 실행 시 클라우드 토큰 비용이 0원으로 작동한다. 결정적 DSL과 의미 기반 UI 인식 기술로 기존 RPA의 취약성과 멀티모달 에이전트의 높은 비용 문제를 동시에 해결했다. 브라우저 자동화 엔진 프루-클라이도 오픈소스로 공개했다.
