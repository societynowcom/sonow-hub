# Anthropic, 새로운 AI 에이전트 "Cowork" 출시

> 개발자도 아닌 일반 사용자를 위한 AI 도구

**AI** | 2026.02.24 | SO,NOW

Anthropic는 AI 에이전트 "Cowork"를 출시했습니다. Cowork는 기존 개발자 중심 도구인 Claude Code의 기능을 일반 사용자가 이해하고 활용할 수 있도록 쉽게 구현했습니다. 핵심은 사용자 지정된 폴더에 접근하여 파일을 읽고 수정하거나 생성하는 데 있는데, 이를 통해 스프레드시트 작성이나 보고서 제작 등의 작업을 자동화합니다.

Cowork의 특징은 단순한 대화형 AI가 아닌 "agentic loop" 기반으로 작동하는 것입니다. 사용자는 작업 지시를 입력하고 AI가 해당 작업을 수행하기 위해 계획을 세우고 각 단계를 실행합니다. 이 과정에서 필요한 경우 추가적인 정보를 요청하거나 수정 사항을 확인합니다. 또한,  Anthropic은 Cowork에 "클라우드 데이터 커넥터" 기능을 탑재하여 사용자가 기존 서비스와의 연동을 가능하게 했습니다.
