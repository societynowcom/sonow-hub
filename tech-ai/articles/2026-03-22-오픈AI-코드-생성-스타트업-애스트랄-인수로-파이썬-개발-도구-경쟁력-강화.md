# 오픈AI, 코드 생성 스타트업 애스트랄 인수로 파이썬 개발 도구 경쟁력 강화

**AI** | 2026.03.22 | SO,NOW

오픈AI가 코드 생성 전문 스타트업 애스트랄을 인수했다. 이번 인수는 오픈AI의 코드 생성 모델 코덱스 성장을 가속화하고 차세대 파이썬 개발자 도구를 강화하기 위한 전략적 움직임이다. AI를 통한 소프트웨어 개발 자동화 경쟁이 본격화되는 가운데, 한국 개발자 커뮤니티에도 새로운 생산성 도구의 확산이 예상된다.
