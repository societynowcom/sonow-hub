# Anthropic Cowork: AI Agent for Non-Technical Users

> How Anthropic's New Product Simplifies AI Integration and Raises Ethical Questions

**AI** | 2026.03.12 | SO,NOW

Anthropic has launched Cowork, an AI agent that extends the functionality of its Claude Code tool to non-technical users. The tool, built in just under a week using Claude Code, promises to revolutionize productivity. However, the launch also raises ethical concerns about data security and user control.
