# 네모트론 ColEmbed V2, 다중모달 검색 기준 새로 정의

> ViDoRe V3 최고 모델 활용하여 성능 향상

**AI** | 2026.02.11 | SO,NOW

네모트론은 인공지능(AI) 기반 텍스트 데이터 분석과 이해 기술을 선도하는 회사이다. 최근에는 이미지와 텍스트를 동시에 처리하는 멀티모달 검색 기술에 집중하고 있다. 이러한 노력의 일환으로 네모트론은 'ColEmbed V2' 모델을 개발했다.

ColEmbed V2는 ViDoRe V3 모델을 기반으로 하며, 이미지와 텍스트 데이터를 효과적으로 학습한다. 특히, 다양한 자료 형태를 처리하는 능력이 강화되어 더욱 정확하고 유용한 검색 결과를 제공할 수 있다. 예를 들어, 사용자가 "초록색 새하얀 튤립 사진"과 같은 문자형 검색어를 입력하면, ColEmbed V2는 이미지 데이터베이스에서 해당 설명에 부합하는 꽃 사진을 찾아줄 수 있다.
