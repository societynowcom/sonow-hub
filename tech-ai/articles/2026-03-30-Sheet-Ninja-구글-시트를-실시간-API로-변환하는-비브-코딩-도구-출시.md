# Sheet Ninja, 구글 시트를 실시간 API로 변환하는 비브 코딩 도구 출시

**AI** | 2026.03.30 | SO,NOW

Sheet Ninja는 2026년 출시된 비브 코딩 도구로, 구글 시트를 실시간 API로 변환합니다. 사용자는 기존 구글 시트 링크를 붙여넣어 CRUD 기능을 갖춘 엔드포인트를 즉시 생성할 수 있으며, Lovable·Bolt·Replit 등 비브 코딩 플랫폼과 연동됩니다. 데이터는 원본 시트에 유지되며 변경사항이 실시간으로 애플리케이션에 반영됩니다.
