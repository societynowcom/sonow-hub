# 버퍼 API 출시, 단일 엔드포인트로 11개 소셜 플랫폼 관리한다

**AI** | 2026.06.03 | SO,NOW

버퍼가 2026년 단일 API 엔드포인트로 11개 소셜 플랫폼에 콘텐츠를 게시·관리할 수 있는 '버퍼 API'를 출시했다. 그래프QL 기반이며 MCP 서버, 명령줄 인터페이스, 사전 제작 자동화 템플릿을 함께 제공한다. AI 어시스턴트나 노코드 도구와 연결하거나 맞춤 통합을 직접 구축할 수 있으며 무료 플랜을 포함한 모든 요금제에서 이용 가능하다.
