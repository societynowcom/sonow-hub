# Anthropic launches Cowork, a Claude Desktop agent that works in your files — no coding required

> Anthropic, 'Cowork'으로 AI 에이전트 시장 공략  ## 새로운 AI 에이전트 툴로 비즈니스 활용성 강화  Anthropic가 새로운 AI 에이전트 기능 'Co

**AI** | 2026.02.25 | SO,NOW

Anthropic가 새로운 AI 에이전트 기능 'Cowork'을 출시했습니다. Claude Code를 기반으로 개발된 Cowork는 일반 사용자가 컴퓨터 파일을 관리하고 작업을 자동화할 수 있도록 합니다. 특히, Anthropic은 Cowork가 단순한 대화형 AI가 아닌 진정한 AI 에이전트라고 주장하며, 폴더 접근권을 통해 파일 읽기, 수정 및 생성 등의 작업을 수행할 수 있다고 설명했습니다.

Cowork는 개발자들이 Claude Code를 비즈니스 용도로 활용하는 모습에서 영감을 얻었습니다. 사용자들은 예상치 못한 방식으로 Claude Code를 활용하여 휴가 계획, 자료 정리, 파일 관리 등 다양한 작업을 수행했습니다.  Anthropic는 이러한 트렌드를 바탕으로 개발자 용도에서 벗어나 일반 사용자도 활용할 수 있는 Cowork를 제작했습니다.

Cowork는 'agentic loop' 방식을 기반으로 하며, 사용자가 지시를 내리면 AI가 계획을 세우고 단계별로 작업을 실행하며 결과를 확인하고 필요시 사용자에게 의견을 구하는 과정을 거칩니다. 또한, 폴더 접근 권한과 연결 기능을 통해 파일 시스템 관리 및 웹 기반 작업까지 수행할 수 있습니다.
