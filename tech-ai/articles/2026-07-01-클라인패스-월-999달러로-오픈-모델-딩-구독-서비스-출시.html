AI 코딩 에이전트 클라인이 월 9.99달러 구독 서비스 클라인패스를 출시했다. GLM, 키미, 딥시크 등 최고 수준의 오픈 가중치 코딩 모델을 하나의 구독으로 제공하며, 표준 API 한도보다 2~5배 높은 속도를 지원한다. 제공사 계정이나 API 키를 따로 관리할 필요 없이 클라인 내부에서 바로 사용 가능하다. 이 서비스는 에이전트형 코딩 워크플로를 더 단순하고 빠른 오픈 모델 스택으로 이용하려는 개발자를 대상으로 한다.
