# Anthropic launches Cowork, a Claude Desktop agent that works in your files — no coding required

> Anthropic, 새로운 AI 에이전트 'Cowork' 출시  ## AI 도구 사용자 경험을 개선하는 데 집중  Anthropic가 새로운 AI 에이전트 'Cowork'를

**AI** | 2026.02.19 | SO,NOW

Anthropic가 새로운 AI 에이전트 'Cowork'를 출시하며 기업 사용자를 위한 AI 솔루션에 대한 도약을 선보였다. Cowork는 개발자들이 사용하는 Claude Code 기능을 일반 사용자에게 확장해 파일 관리, 문서 생성 등 다양한 작업을 자동화한다.

Anthropic은 최근 성공적인 AI 코드 도구 'Claude Code'를 기반으로 새로운 제품을 개발했다. 이는 개발자가 사용하는 복잡한 명령어 대신 친숙한 파일 시스템 인터페이스로 접근할 수 있도록 하여 일반 사용자도 쉽게 활용할 수 있도록 설계되었다.  Anthropic은 Cowork를 'AI가 당신의 일을 하는 동료처럼 느껴질 정도'로 홍보하고 있으며, 지난주에 macOS 버전을 출시했다.

Cowork는 사용자의 특정 폴더에 접근하여 파일을 읽고 수정하거나 새롭게 생성할 수 있는 기능을 제공한다.
