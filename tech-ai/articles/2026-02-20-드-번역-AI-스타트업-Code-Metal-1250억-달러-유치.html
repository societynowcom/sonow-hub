AI로 코드 번역하는 Code Metal, 국방 산업을 선도하며 성장

AI | 2026.02.20 | SO,NOW

Code Metal은 2023년 설립된 스타트업으로 최근 1250억 달러의 B 라운드 자금을 확보했다. 이는 기존 투자자와 새로운 투자자가 참여한 자금 조달이며, A 라운드 자금(360억 달러)를 포함하면 총 자금은 약 1610억 달러에 달한다. Code Metal의 주요 목표는 고수준 프로그래밍 언어인 Python, Julia, Matlab, C++ 코드를 저수준 언어 또는 특정 하드웨어에 실행되는 코드로 번역하는 것이다.

Code Metal은 L3Harris, RTX (전 Raytheon), 미국 공군 등 국방 관련 기업과 계약을 체결했으며, 일본 전자 회사 Toshiba와도 협력하고 있다. 또한 대형 칩 기업과의 파트너십도 논의 중이다. Code Metal은 코드 번역 과정에서 테스트 하네스를 생성하여 코드의 정확성을 평가한다고 주장하며, 이를 통해 오류 발생 가능성을 최소화하는 것을 강조한다.
