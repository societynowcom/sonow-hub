# 플루리 AI, 기업 데이터 맥락을 AI 에이전트에 제공하는 통합 지능층 출시

**AI** | 2026.07.26 | SO,NOW

기업용 AI 데이터 플랫폼 플루리 AI가 이번 주 제품헌트를 통해 공개됐다. 플루리는 검증 가능한 지식 그래프 데이터베이스를 바탕으로 기업 데이터를 하나의 진실 공급원으로 연결해 대규모 언어 모델 에이전트에 출처가 명시된 답변을 제공한다. 기존 검색 보강 생성 방식의 한계를 넘어 직접 구조화된 데이터를 질의하며, 모든 요청마다 권한을 확인한다.
