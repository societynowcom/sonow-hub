AI 에이전트를 위한 소셜 청취 도구 옥톨렌스, API 중심으로 전면 재설계

AI | 2026.07.08 | SO,NOW

옥톨렌스가 AI 에이전트 시대에 맞춰 소셜 청취 서비스를 데이터 레이어로 전환했다. 15개 이상 공개 채널에서 키워드 언급을 수집하고 AI로 필터링한 JSON을 API와 웹훅, MCP를 통해 제공한다. 슬랙과 CRM, 데이터 웨어하우스, 에이전트에 직접 연동 가능하며 유료 요금제는 첫날부터 데이터 소유권을 보장한다.
