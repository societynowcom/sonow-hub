# 리플리카스, 클라우드 VM에서 클로드 코드와 코덱스 동시 실행 가능

**AI** | 2026.06.05 | SO,NOW

리플리카스가 클라우드 가상머신에서 클로드 코드와 코덱스 등 코딩 에이전트를 격리 실행하는 서비스를 출시했다. 슬랙·리니어·깃허브에서 작업을 전달하면 에이전트가 실제 개발 환경에서 코드를 작성하고 PR을 반환한다. 개인 API 키와 구독을 그대로 사용할 수 있으며, 랩탑을 닫아도 작업이 중단되지 않는다. 자체 PR의 95%를 이 서비스로 처리했다고 밝혔다.
