# YC와 a16z 스타트업 6600곳 데이터, 30초면 연동 가능한 오픈소스 API 등장

**AI** | 2026.07.10 | SO,NOW

익스플로어YC가 Y 콤비네이터와 a16z 소속 6600개 이상 스타트업 데이터를 통합한 오픈소스 API를 출시했다. 자금 조달 내역, 단계, IPO·M&A 엑싯, 창업자 정보를 제공하며 VC별·배치·산업·국가별 필터와 검색이 가능하다. 무료 API 키 발급 후 30초 만에 연동할 수 있고 웹 앱에서 지도·분석·실시간 채용 게시판·AI 도구도 이용할 수 있다.
