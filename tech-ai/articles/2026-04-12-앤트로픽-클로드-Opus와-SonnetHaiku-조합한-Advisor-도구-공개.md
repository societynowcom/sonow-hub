# 앤트로픽, 클로드 Opus와 Sonnet·Haiku 조합한 'Advisor 도구' 공개

**AI** | 2026.04.12 | SO,NOW

앤트로픽이 2026년 4월 10일 Messages API 기반 클로드 Advisor 도구를 출시했다. Opus 모델은 조언자로, Sonnet이나 Haiku 모델은 실행자로 pairing해 협업하게 한다. 개발자들은 고비용 고성능 모델을 효율적으로 활용하면서도 복잡한 에이전트 작업을 처리할 수 있게 됐다.
