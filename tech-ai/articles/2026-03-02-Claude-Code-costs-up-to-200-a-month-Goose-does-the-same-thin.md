# Claude Code costs up to $200 a month. Goose does the same thing for free.

> 무료 AI 코드 생성: Goose의 부상  ## 클라우드 독립, 오픈소스 AI 개발자를 위한 새로운 옵션  Goose는 Block에서 개발한 무료 오픈소스 AI 기반 코드 생

**AI** | 2026.03.02 | SO,NOW

Goose는 Block에서 개발한 무료 오픈소스 AI 기반 코드 생성 도구입니다. 클라우드에 의존하지 않고 사용자의 로컬 머신에서 실행되며, Claude Code와 같은 유사 기능을 제공합니다.  구독 비용 없이 24시간 언제든지 사용 가능하며, 개발자는 자신의 데이터를 완벽히 관리할 수 있습니다.

Goose는  '툴 콜링' 기능을 통해 코드 생성뿐만 아니라 파일 작성, 테스트 실행, GitHub 요청 처리 등 다양한 작업을 자동화합니다. 사용자가 선택한 언어 모델을 연결하여 사용할 수 있으며, Ollama와 같은 도구를 이용해 로컬로 운영할 수 있습니다.
