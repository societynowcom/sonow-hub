# 모든 API를 AI 에이��트용 MCP 서버로 변환하는 도구 등장

**AI** | 2026.06.21 | SO,NOW

API 투 MCP가 REST, 그래프QL, SaaS, 내부 비즈니스 API를 AI 에이전트가 사용 가능한 호스팅 MCP 서버로 변환하는 도구를 출시했다. 대시보드에서 시각적 구성이 가능하며 AI 에이전트가 API 문서를 기반으로 도구를 생성·테스트·배포할 수 있다. 챗GPT, 클로드, 코덱스, 커서, VS 코드, 안티그래비티 등 다양한 에이전트와 연결되며 OAuth와 보안 인증을 지원한다.
