# 금융위, 가상자산 시세조종 혐의자 2건 수사기관에 통보

**TECH & AI** | 2026.04.29 | SO,NOW

금융위원회는 2026년 4월 29일 제8차 정례회의에서 가상자산 시세조종 사건 2건의 혐의자를 수사기관에 통보했다. 특정 가상자산 미리 사들인 후 고가매수 주문으로 가격 조종하고 API 키 대여해 통정매매한 사례에서 수천만원 부당이득이 발생했다. 금감원은 API 키 관리 강화와 거래소 감시 시스템 고도화를 추진한다.
