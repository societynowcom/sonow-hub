# Circle to Search 업데이트, 이미지 속 여러 객체 검색 가능

> 이미지 하나에서 여러 개체 정보 찾아낼 수 있게 되었다.

**AI** | 2026.02.28 | SO,NOW

Circle to Search는 구글 AI팀이 개발한 이미지 검색 기술입니다. 사용자들이 특정 객체를 이미지에 표시하면 Circle to Search가 해당 객체와 관련된 정보를 제공하는 시스템입니다. 이전에는 한 이미지에서 하나의 객체만 검색 가능했지만, 최신 업데이트로 여러 객체를 동시에 검색할 수 있게 되었습니다.

이 기능은 이미지 인식 및 검색 기술의 발전을 보여주는 사례입니다. AI 알고리즘이 이미지 속 여러 개체를 구분하고 각 객체에 대한 정보를 추출하는 능력이 향상되었기 때문입니다. 이 업데이트는 사용자가 이미지를 더 효율적으로 분석하고 활용할 수 있도록 도와줍니다.
