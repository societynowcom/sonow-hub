# Claude Code costs up to $200 a month. Goose does the same thing for free.

> 무료 오픈소스 AI 코딩 도구, Goose의 등장 ## 클라우드 의존도 없이 개발자의 자율성을 강화하는 무료 AI 솔루션  Goose는 Block(Square 전)에서 개발

**AI** | 2026.02.23 | SO,NOW

Goose는 Block(Square 전)에서 개발한 오픈소스 AI 에이전트로 클라우드 기반 서비스와 달리 로컬 머신에서 실행됩니다.  
클라우드 의존성 없이 사용자의 데이터를 자체적으로 관리하며, 구독료 없이도 사용할 수 있습니다.

Goose는 일반 AI 코딩 도구와 달리 다양한 언어 모델을 지원하는 독점적 특징을 가지고 있습니다.  
사용자는 Ollama와 같은 도구를 통해 오픈소스 모델을 로컬로 실행하고, 혹은 Anthropic의 Claude 모델과 같은 API 연결을 사용할 수 있습니다. 이는 개발자가 필요에 따라 다양한 모델을 선택하고 활용할 수 있는 유연성을 제공합니다.
