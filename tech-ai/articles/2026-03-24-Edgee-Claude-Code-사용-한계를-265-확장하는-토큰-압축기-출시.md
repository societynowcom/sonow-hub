# Edgee, Claude Code 사용 한계를 26.5% 확장하는 토큰 압축기 출시

**AI** | 2026.03.24 | SO,NOW

AI 게이트웨이 스타트업 Edgee가 클로드 코드의 플랜 한계를 26.5% 늘리는 압축기를 출시했다. 사용자와 Anthropic API 사이에 위치해 프롬프트의 중복 컨텍스트를 제거한다. 동일 작업에서 표준 클로드 코드는 21개 지시에서 중단됐으나 압축 적용 시 26.5개 지시까지 처리했다. 개발자 도구 카테고리에서 주목받고 있다.
