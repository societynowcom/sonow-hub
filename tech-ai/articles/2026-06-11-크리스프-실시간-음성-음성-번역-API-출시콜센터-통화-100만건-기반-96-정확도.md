# 크리스프, 실시간 음성-음성 번역 API 출시…콜센터 통화 100만건 기반 96% 정확도

**AI** | 2026.06.11 | SO,NOW

음성 AI 기업 크리스프가 실시간 음성-음성 번역 API를 출시했다. 실제 콜센터 통화 100만 건으로 훈련해 배경 소음과 억양에도 96% 정확도를 달성했으며, 환자 안전 사고는 0건이다. 61개 이상 언어를 조합 제약 없이 지원하며 개발자 대시보드 가입 시 60분 무료 크레딧을 제공한다.
