# 라쿠텐, OpenAI 코드엑스 도입으로 소프트웨어 평균 복구 시간 50% 단축

**AI** | 2026.03.16 | SO,NOW

라쿠텐이 OpenAI의 코드엑스를 개발 프로세스에 통합해 시스템 장애 평균 복구 시간(MTTR)을 50% 단축했다. CI/CD 파이프라인 자동화와 자동 코드 리뷰를 통해 몇 주 내에 전체 스택을 구축하고, 개발 생산성과 운영 효율성을 동시에 향상시켰다.
