# 아마존, 비용 분석 자동화하는 AWS 핀옵스 에이전트 공개 미리보기 출시

**TECH & AI** | 2026.06.29 | SO,NOW

아마존이 AWS 핀옵스 에이전트를 공개 미리보기로 출시했다. 이 관리형 서비스는 비용 이상 징후를 자동으로 조사하고, AWS 활동 데이터와 연계해 원인을 분석하며, 슬랙이나 지라 같은 협업 도구와 통합된다. 아마존 베드록 기반으로 구축된 이 에이전트는 자연어 비용 질문에도 응답할 수 있다.
