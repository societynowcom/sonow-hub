# 파이어크롤, 웹 데이터 수집 자동화 에이전트 '프로메테우스' 공개

**AI** | 2026.06.15 | SO,NOW

웹 데이터 API 기업 파이어크롤이 2026년 6월, 자연어 설명만으로 웹 데이터 수집 코드를 자동 작성하고 실행·유지보수까지 수행하는 실험적 에이전트 '프로메테우스'를 출시했다. 사용자는 원하는 데이터를 평문으로 설명하면 에이전트가 사이트를 분석해 타입스크립트 코드를 생성하고 검증까지 마친 결과물을 제공받는다. 코드를 직접 소유하거나 호스팅을 맡길 수 있으며, 페이지 변경 시 자동 복구 기능도 갖췄다.
