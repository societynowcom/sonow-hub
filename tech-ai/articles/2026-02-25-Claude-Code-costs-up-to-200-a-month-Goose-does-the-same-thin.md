# Claude Code costs up to $200 a month. Goose does the same thing for free.

> 무료 AI 코드 에이전트 'Goose', 개발자들의 마음을 사로잡다   ## 저렴한 가격 대신 사용자의 자율성을 강조하는 새로운 패러다임   Goose는 블록(Block, 전

**AI** | 2026.02.25 | SO,NOW

Goose는 블록(Block, 전 Square)에서 개발된 오픈소스 AI 에이전트로, 클라우드 기반 코드 생성 도구인 Claude Code와 유사한 기능을 제공하지만 완전히 무료입니다. 사용자의 지역 컴퓨터에 실행되며 구독비나 이용 제한 없이 작동하여 개발자에게  최대 수준의 자율성을 제공합니다.

클라우드 기반 AI 코드 생성 도구인 Claude Code는 높은 가격과 사용량 제한으로 인해 개발자들 사이에서 반발을 일으키고 있었습니다. 이에 반하여 Goose는 모든 기능이 무료로 이용 가능하며, 사용자가 직접 컴퓨터에 설치하고 관리할 수 있어 개발자의 자율성을 강조합니다.

Goose는 Ollama와 같은 도구를 통해 다양한 오픈소스 언어 모델과 연결될 수 있으며, '기능 호출' 기술을 통해 코드 생성뿐만 아니라 파일 작성, 테스트 실행 등 다양한 작업을 자동화할 수 있습니다.
