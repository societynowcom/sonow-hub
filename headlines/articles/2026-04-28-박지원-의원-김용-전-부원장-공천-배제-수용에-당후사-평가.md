# 박지원 의원, 김용 전 부원장 공천 배제 수용에 '��당후사' 평가

**정책브리핑** | 2026.04.28 | SO,NOW

박지원 더불어민주당 의원은 2026년 4월 28일 김용 전 민주연구원 부원장의 공천 배제 수용 결정을 '선당후사 정신'이라며 높이 평가했다. 김 전 부원장은 당일 기자회견에서 검찰 개혁 싸움을 계속하겠다는 의지를 밝혔으며, 양측 모두 다가오는 선거 승리를 위해 당 내부 통합이 필요하다고 강조했다.
