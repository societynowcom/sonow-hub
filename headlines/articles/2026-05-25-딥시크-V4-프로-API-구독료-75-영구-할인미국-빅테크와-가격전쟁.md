# 딥시크, V4 프로 API 구독료 75% 영구 할인…미국 빅테크와 가격전쟁

**HEADLINES** | 2026.05.25 | SO,NOW

중국 AI 스타트업 딥시크가 2026년 5월 23일부터 플래그십 모델 V4 프로의 API 구독료를 75% 영구 할인했다. 혼합 토큰 100만개당 가격이 0.18달러로 경량 모델 수준이며, 동일 벤치마크 비용이 오픈AI GPT-5.5 대비 12.5배 저렴하다. 화웨이 칩 최적화와 아키텍처 혁신이 저가를 가능하게 했다.
