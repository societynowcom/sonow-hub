# Microsoft and OpenAI Revise Landmark Partnership, Ending Exclusive Cloud Revenue-Sharing

**NEWS** | 2026.05.09 | JustNow

Microsoft and OpenAI restructure their AI partnership, ending exclusive arrangements and revenue-sharing. The new deal allows Microsoft to invest in competing AI startups while maintaining Azure as OpenAI's primary cloud provider.
