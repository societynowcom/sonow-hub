# Chrome on Android now supports approximate instead of precise location sharing

**NEWS** | 2026.05.09 | JustNow

Google announced Chrome on Android now lets users share approximate location with websites, enhancing privacy. The feature gives users more control over data shared, with precise location available when needed. Desktop support is planned.
